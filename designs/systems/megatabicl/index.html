MegaTabICL: Efficient Scaling of Tabular Foundation Model Pretraining

We characterize the TFM pretraining workload to build MegaTabICL, an exact 3.86x-cheaper implementation of TabICLv2 pretraining, and use it for a first billion-parameter scaling study showing the compute-optimal parameter count growing with budget.

three workload mismatches

01

Heavy-tailed prior generationTables are generated on CPU with median 218 ms and p99 2893 ms; 37% of attempts are rejected, using 36% of sampler time. MegaTabICL keeps several batches in generation so the slowest table no longer stalls a step.

02

Heterogeneous input shapesRows and columns vary by orders of magnitude per table, which breaks compiled graphs. Shape-independent dynamic compilation, shape-agnostic attention kernels and a cost model for balancing micro-batches across ranks.

03

Compute in low-parameter layersThe column embedder and row interactor hold under 5% of parameters but over half of step time. 78% of tensors hold 2.5% of parameters, so a grouped optimizer step goes from 158.9 ms to 14.2 ms.

bf16

Stabilized BF16 recipeThe only deviation from the reference recipe: QASSMax stays in FP32 and moves from Muon to AdamW.
